# Маленький корректный банк

Пять вопросов показывают четыре типа и все пять уровней. Используйте этот банк
для первой общей сборки. Ожидаемая сводка находится в `small_scan_expected.txt`.
В итоговую сдачу вопросы этого примера не добавляются.

```sh
python3 src/main.py examples/small_bank/ --scan
python3 src/main.py examples/small_bank/ --seed 4711
```
