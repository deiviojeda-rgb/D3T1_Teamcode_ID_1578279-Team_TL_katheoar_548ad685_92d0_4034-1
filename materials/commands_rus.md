# Команды по этапам работы

Все команды запускаются из корня репозитория. `python3` — установленный на станции Python. `src/partner/examiner.py` — готовый проверяющий, его писать не нужно. Код из `src/partner` не меняйте и не импортируйте в реализацию.

## День 3 Первая сборка

Показать сводку маленького банка своей программой:

```sh
python3 src/main.py examples/small_bank/ --scan
```

Сравните вывод с `examples/small_scan_expected.txt` на экране. Затем пройдите сессию сами:

```sh
python3 src/main.py examples/small_bank/ --seed 4711
```

После реализации загрузки запустите этап 1; после четырёх типов ответа — этап 2:

```sh
python3 src/partner/examiner.py --task 1 src/main.py datasets/
python3 src/partner/examiner.py --task 2 src/main.py datasets/
```

Этап 1 проверяет сводку корректного маленького банка. Этап 2 вызывает функции загрузки и проверки ответа. Заготовки сначала эти проверки не проходят: это ожидаемо, пока вы не написали реализацию.

## День 4 Проверка поведения

Проверить финальные вопросы команды и сохранность готовых данных:

```sh
python3 src/partner/examiner.py --bank-check datasets/
```

До добавления 20 вопросов эта команда сообщит, чего не хватает. Ошибки формата исправляйте в своих вопросах. Она не проверяет человеческий смысл формулировок — для этого нужна взаимная проверка.

Запустить полный технический прогон:

```sh
python3 src/partner/examiner.py --run src/main.py datasets/
```

| Этап | Что проверяется |
|---|---|
| 1 | Загрузка и сводка корректного маленького банка |
| 2 | Четыре типа ответов, пустые ответы и неизвестные метки |
| 3 | Полный диалог, EOF, пустые ответы и пустой банк, воспроизводимость и `--explain` |
| 4 | Неизменность знаний после «не принят»; 15 идеальных сессий; зависимость траектории от ответов |

Успех всех четырёх этапов даёт `КОД ПРИНЯТ`. Для повторения отдельного упавшего этапа используйте `--task НОМЕР` вместо `--run`.

Посмотреть список учебных собеседников и запустить выбранного:

```sh
python3 src/partner/examiner.py --play
python3 src/partner/examiner.py --play невнимательный src/main.py datasets/
python3 src/partner/examiner.py --play угадыватель src/main.py datasets/
```

`ровный-1`…`ровный-5` следуют идеальной модели из README. Остальные профили помогают обсудить случайные ошибки, угадывание и противоречия. От них не требуется точного совпадения итогового уровня. Проверяющий показывает ход сессии прямо в терминале.

Показать собственное объяснение на живой сессии:

```sh
python3 src/main.py datasets/ --seed 4711 --explain
```

Для завершения ввода на Linux нажмите Ctrl-D в пустой строке. Не сохраняйте журнал вручную.

## Перед отправкой

```sh
bash ci-scripts/test.sh
```

Сценарий проверяет обязательные файлы кода и данных, запускает линтер, проверку банка и все четыре этапа на новом контрольном числе. Если есть ошибка — исправьте её до отправки. Итоговый `ВСЁ СОШЛОСЬ` означает техническую готовность; смысл вопросов и понимание программы обсуждаются на приёмке.
